# Artifact Examples

This directory contains examples of the output generated by the sitemap discovery script.

## url-inventory.json

Complete URL inventory with metadata for all discovered URLs:

```json
{
  "metadata": {
    "discoveredAt": "2026-02-05T23:40:13.995Z",
    "sitemapIndexUrl": "https://daikintucson.com/sitemap_index.xml",
    "totalUrls": 2,
    "sitemapsDiscovered": 1
  },
  "sitemaps": [
    {
      "url": "https://daikintucson.com/page-sitemap.xml",
      "entries": [
        {
          "loc": "https://daikintucson.com/",
          "lastmod": "2024-01-15",
          "priority": "1.0",
          "changefreq": "weekly"
        },
        {
          "loc": "https://daikintucson.com/about",
          "lastmod": "2024-01-10",
          "priority": "0.8",
          "changefreq": "monthly"
        }
      ]
    }
  ]
}
```

## url-inventory.csv

Spreadsheet-friendly format for analysis:

```csv
URL,LastModified,Priority,ChangeFrequency,Sitemap
"https://daikintucson.com/","2024-01-15","1.0","weekly","page-sitemap.xml"
"https://daikintucson.com/about","2024-01-10","0.8","monthly","page-sitemap.xml"
```

## sitemap-counts.json

Summary statistics:

```json
{
  "discoveredAt": "2026-02-05T23:40:13.995Z",
  "sitemapIndex": "https://daikintucson.com/sitemap_index.xml",
  "sitemaps": [
    {
      "url": "https://daikintucson.com/page-sitemap.xml",
      "urlCount": 2
    }
  ],
  "totals": {
    "sitemapsFound": 1,
    "totalUrlsDiscovered": 2
  }
}
```

## Usage in Analysis

These artifacts can be used for:
- Scope planning for the website rebuild
- URL structure analysis
- Content inventory review
- Migration planning
- Priority and update frequency analysis
