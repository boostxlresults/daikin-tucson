# Artifact Outputs

This directory contains the output files generated by the sitemap discovery script.

## url-inventory.json

Complete URL inventory with all discovered URLs and their metadata.

**Top-level keys:**
- `metadata` - Discovery metadata including timestamp, sitemap index URL, total URL count, and sitemaps discovered count
- `urls` - Array of URL objects containing `loc`, `lastmod`, `priority`, `changefreq`, and `sitemap` source attribution
- `sitemapCounts` - Array of sitemap objects with URL counts per sitemap

## url-inventory.csv

Spreadsheet-friendly comma-separated format of the URL inventory.

**Columns:**
- `loc` - URL location
- `lastmod` - Last modified date
- `priority` - Priority value
- `changefreq` - Change frequency
- `sitemap` - Source sitemap URL

## sitemap-counts.json

Summary statistics for discovered sitemaps.

**Top-level keys:**
- `discoveredAt` - ISO timestamp of discovery
- `sitemapIndexUrl` - URL of the sitemap index
- `totals` - Object containing `totalUrlsDiscovered` and `sitemapsFound`
- `sitemaps` - Array of sitemap objects with `sitemap` URL and `urlCount`

## Usage in Analysis

These artifacts can be used for:
- Scope planning for the website rebuild
- URL structure analysis
- Content inventory review
- Migration planning
- Priority and update frequency analysis
